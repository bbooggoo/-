v9는 사용자 지정 10개 항목을 유지하며, PPT 질의·답변을 정형 DB로 축적하고 승인에 따른 자동 갱신과 대상별 반영 이력을 확인하는 구성을 중심으로 설명합니다. 후속 PJT 및 리트로핏 재사용을 포함합니다.

2026-10-25 답변에 따라 승인값 80에 대해 기존값 100이 재접수되면 80 유지·추가 질의 없음으로 정책 방향을 구체화했습니다. 제조 기술팀과 룰셋 협의 및 자동 처리 구현 여부는 미확정입니다. 환경그룹 기준의 케미컬 대 폐액탱크 다대일 관계, UT 전체 삭제와 단일 값 누락 오류의 구분, GCS 분할 접수의 총량 집계 부담을 반영했습니다.

현재 기능, 추가 설계 및 향후 고도화를 구분합니다. 적용 예정일은 2026-11-30이며 질의 기간 4주 단축과 MM 기존 절반 이하 감소는 실증 전 예상입니다. FAB lateral 발주·제작 도면과 연계되는 일정 효과를 설명하며 전체 일정의 동일한 단축을 보장하지 않습니다.

선행조사는 공개자료 기반 1차 조사입니다. 외부 공동개발·공동출원 약정은 없고 제품 모델·출하시기는 사내 업무 플랫폼으로 해당 없음입니다. 별도 외부 발표 계획과 사용자 허용 공개 GitHub 게시 이력은 구분합니다. 이전 문서보다 최신 초안을 우선 참고합니다.

v10은 동일 건설코드 내 설비모듈별 UT 식별을 구체화합니다. 분할 보충·지정 범위 교체를 구분하고 코드·모듈·UT·설비 대수의 변경점에 대한 대공정 담당자 확인 및 질의 연결을 추가 설계로 반영했습니다. 현재 DB 갱신 시점은 확인 필요입니다. GCS 양방향 검증은 미구현이며 환경그룹 엑셀의 명칭 표준화 또는 매핑리스트 작성이 필요합니다.
