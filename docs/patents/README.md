현재 초안은 제원 질의 결과의 실제 최종 반영 확인을 첫 번째 중심으로 정리합니다. GCS 케미컬·슬러리와 폐액의 장비 단위 양방향 정합성 검증은 추가 검토 후보입니다. 복수 자재가 하나의 폐액에 대응할 수 있으며 구체 사례와 구현 여부는 추후 확인합니다.

데모 구현, 향후 설계안 및 목표 효과를 구분합니다. 선행조사는 공개자료 기반 1차 조사이며 정식 출원 가능성이나 실시자유 판단 결과가 아닙니다. 이전 초안에는 이후 수정된 내용이 있으므로 최신 초안을 우선 참고합니다.

사용자 요청에 따라 앞으로 특허초안 수정 내용은 이 저장소에도 반영하고, 답변 마지막 줄에는 최신 초안의 GitHub 링크를 제공합니다.

최신 v6는 사용자 지정 10개 항목에 따라 서지정보, 대표 선행기술 비교, 상세 설명, 변형 실시예, 용어, 희망 청구범위, 적용 확인 방법, 효과 및 공정·설계 변화를 정리합니다. 공동출원 여부·외부 발표·제품 모델·출하시기는 확인된 범위만 기재하며, 기존 GitHub 공개 이력도 포함합니다.
