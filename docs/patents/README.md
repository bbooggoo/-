이전 v7는 사용자 지정 10개 항목을 유지합니다. 설계사 PPT 질의와 공정별 기술팀 답변을 장비·항목·오류 유형·확정 조치·실제 반영·시점이 연결된 정형 DB로 축적하고, 최종 반영을 확인하는 구조를 중심으로 설명합니다. 이 데이터의 후속 PJT 및 리트로핏 재사용을 강조합니다.

오류 유형·검증된 적용 조건을 이용한 다음 PJT 자동 보정은 향후 고도화입니다. 질의 효율화에 따른 선출도 조기 발행, 연계 시공 착수와 설계·시공 중첩 확대, 임시사용승인 목표시점 단축 기여는 업무 의존관계에 따른 기대 효과로 구분합니다. 질의 기간 약 4주 단축은 실증 전 목표이며 후속 일정이 각각 4주씩 단축된다는 뜻은 아닙니다.

GCS 케미컬·슬러리와 폐액의 장비 단위 양방향 정합성 검증은 추가 후보입니다. 복수 자재가 하나의 폐액에 대응할 수 있으며 구체 규칙·사례와 구현 여부는 추후 확인합니다.

데모 구현·추가 설계·향후 개발·목표 효과를 구분합니다. 선행조사는 공개자료 기반 1차 조사이며 정식 출원 가능성이나 실시자유 판단 결과가 아닙니다. 공동출원·제품 모델·출하시기 등은 확인된 범위만 기재하며 GitHub 공개 이력을 포함합니다. 이전 문서보다 최신 초안을 우선 참고합니다.

사용자 요청에 따라 앞으로 특허초안 수정 내용은 이 저장소에도 반영하고 답변 마지막 줄에는 최신 초안의 GitHub 링크를 제공합니다.

최신 v8은 2026-10-24 사용자 확인을 반영합니다. 승인 시 DB 자동 갱신과 수정 이력, 대상별 추천값 적용·유지, 다른 추천값의 통합 검토 방침, 이전 버전 셀 조회·단계별 복원 및 제원분석 탭 기능을 구체화했습니다. 별도의 확정값·현재값 재대조 엔진을 구현 기능으로 전제하지 않습니다. 현장 적용은 2026-11-30 예정이며 4주 단축은 실증 전 목표입니다. 일정 효과는 FAB 내 lateral 발주·제작 도면을 중심으로 검토합니다.

외부 공동개발·공동출원 약정은 없고 사내 업무 플랫폼이므로 제품 모델·출하시기는 해당 없음으로 기재합니다. 별도 외부 발표 계획과 사용자 허용 GitHub 게시 이력은 구분합니다. 공개 저장소 상태를 안내한 후 사용자가 v8 업로드를 명시적으로 요청했습니다.
