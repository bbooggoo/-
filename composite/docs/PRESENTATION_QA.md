- 통합 설계 스튜디오, 생산설비 BOX·인프라 레이어, 단위·예상 BOX 수·미지원 객체 검수, 편집 가능한 Bay와 선택형 인프라 구역, 실제 CAD 이동과 DB 재조회 반영.

## 기능 근거와 한계

소개 내용은 구현 담당이 전달한 44/44 자동 테스트 통과 및 실제 UI 검증 결과에 맞췄으며, 자산 작업에서 애플리케이션 테스트를 중복 실행하지 않았음. 해당 결과는 공통 발표자 노트에도 제한과 함께 기록.

- 실제 공개 DWG의 6개 객체를 브라우저 파서로 처리해 원본·객체 DB 저장 확인. 실제 CAD 끌기 후 R3 저장, 다시 읽은 좌표 유지, 원본 JSON과 변경 이력 확인.
- API 테스트: 인증·소유자 격리·업로드 중복 처리·개정 충돌·원본 바이트 보존·검수 조건 차단 확인.
- BOX 보정 합성 예시: 0.01 m 틈, 0.02 m 허용오차에서 선 폐합 및 BUILD_CODE의 FAB-101 통합 두 수정, 누락 코드 경고 7건을 유지. 분석 후 변경 시 후보 무효화, 경고 메타데이터 저장 및 재분석 전 검수 차단 확인.
- 실제 삼성 프로젝트 DWG는 제공되지 않았음. 파일 선택 자동화는 시간 초과로 끝났으며, 공개 샘플 버튼의 동일 File 처리 경로로 확인. 실제 사용자 파일의 전체 생산 검증으로 주장하지 않음.
- 내장 예시의 설비·컴포짓 수치는 엔진을 직접 실행해 `sample-evidence-dwg-final2.json`으로 기록. 업로드 DWG 처리 성능이나 회사 기준을 나타내지 않음.
